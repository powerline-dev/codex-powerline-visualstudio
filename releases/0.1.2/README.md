# Codex Powerline for Visual Studio 0.1.2

[Download the Visual Studio VSIX](codex-powerline-visualstudio-0.1.2.vsix).

## Change

The **View > Other Windows > Codex Powerline** command now shows the Powerline
icon from the VS Code repository. A 16 × 16 PNG copy is embedded in the command
table, so the menu shows the icon before the extension loads.

## Install or update

1. Close all Visual Studio instances.
2. Open the VSIX and select your Visual Studio installation.
3. Reopen Visual Studio and select **View > Other Windows > Codex Powerline**.

This package upgrades earlier versions. Requirements are unchanged: Windows
x64, Visual Studio 2022 17.14+ or 2026, x64 Node.js 22.12+, both CLIs, and WebView2.

See [SHA256SUMS.txt](SHA256SUMS.txt) for the download checksum and the
[main README](../../README.md#-install) for setup.
